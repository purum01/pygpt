tuple

tuple의 특징과 메소드를 설명해주세요
tuple은 변경 불가능한(immutable) 시퀀스 타입입니다. 한 번 만들어진 tuple의 요소는 추가·삭제·수정할 수 없습니다. 이 특성 덕분에 변하지 않아야 할 데이터(좌표, 날짜, 설정값 등)를 다룰 때 주로 사용합니다.

메소드가 list에 비해 적은 이유도 immutable 특성 때문입니다. tuple이 제공하는 메소드는 다음 두 가지입니다.

count(x)

  • tuple 내에서 x 값이 등장하는 횟수를 반환합니다.
  • 예: t = (1, 2, 3, 2, 4) 에서 t.count(2) 는 2를 반환합니다.

index(x)

  • tuple 내에서 x 값이 처음으로 나타나는 위치(인덱스)를 반환합니다.
  • x가 존재하지 않으면 ValueError가 발생합니다.
  • 예: t = (1, 2, 3, 2, 4) 에서 t.index(3) 은 2를 반환합니다.
tuple 메소드 예제 코드를 보여주세요 

# tuple 생성
animals = ('dog', 'cat', 'bird', 'dog', 'dog', 'cat')

# count() : 등장 횟수 세기
print(animals.count('dog'))   # 3
print(animals.count('cat'))   # 2
print(animals.count('bird'))  # 1

# index() : 위치 찾기
fruits = ('apple', 'banana', 'cherry', 'orange')

print(fruits.index('cherry'))  # 2
print(fruits.index('apple'))   # 0

# tuple은 변경 불가능 (immutable)
# fruits[0] = 'mango'  →  TypeError 발생!
마블 캐릭터 등장 횟수 세기 

characters = ('Spider-Man', 'Iron Man', 'Captain America', 'Spider-Man', 'Hulk', 'Iron Man')

spiderman_count = characters.count('Spider-Man')
ironman_count   = characters.count('Iron Man')

print(f"Spider-Man 등장 횟수: {spiderman_count}")  # 2
print(f"Iron Man 등장 횟수: {ironman_count}")       # 2
내 생일 찾기 

birthdays = ('1월 20일', '4월 5일', '7월 8일', '10월 12일')

mom_idx = birthdays.index('4월 5일')
my_idx  = birthdays.index('10월 12일')

print(f"엄마의 생일은 {mom_idx + 1}번째입니다.")  # 2번째
print(f"내 생일은 {my_idx + 1}번째입니다.")       # 4번째
