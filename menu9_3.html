예외 강제 발생

raise 명령문에 대해 설명해주세요
raise는 개발자가 직접 예외를 발생시키는 명령문입니다. 잘못된 값이 들어왔을 때 즉시 오류를 알려 문제를 조기에 발견할 수 있습니다.

기본 사용법


raise 예외타입("오류 메시지")

예제


def divide(x, y):
    if y == 0:
        raise ZeroDivisionError("0으로 나눌 수 없습니다.")
    return x / y

try:
    result = divide(10, 0)
except ZeroDivisionError as e:
    print(f"오류 발생: {e}")
# 오류 발생: 0으로 나눌 수 없습니다.
  • try 없이 raise만 쓰면 프로그램이 바로 종료됩니다.
  • try-except와 함께 쓰면 오류를 잡아 안내 메시지를 출력할 수 있습니다.
입력값 검증에 활용하기
함수 안에서 잘못된 입력값을 검사하고 raise로 즉시 알려주는 패턴이 자주 쓰입니다.

나이 범위 검증


def check_age(age):
    if age < 0 or age > 150:
        raise ValueError(f"올바르지 않은 나이입니다: {age}")
    return age

try:
    check_age(-5)
except ValueError as e:
    print(f"오류: {e}")
# 오류: 올바르지 않은 나이입니다: -5

점수 범위 검증


def set_score(score):
    if score < 0 or score > 100:
        raise ValueError(f"점수는 0~100 사이여야 합니다. 입력값: {score}")
    return score

try:
    result = set_score(150)
    print(f"등록된 점수: {result}")
except ValueError as e:
    print(f"오류: {e}")
# 오류: 점수는 0~100 사이여야 합니다. 입력값: 150

문자열 길이 검증


def set_username(name):
    if len(name) < 2:
        raise ValueError("이름은 2글자 이상이어야 합니다.")
    if len(name) > 10:
        raise ValueError("이름은 10글자 이하여야 합니다.")
    return name

try:
    print(set_username("김"))
except ValueError as e:
    print(f"오류: {e}")
# 오류: 이름은 2글자 이상이어야 합니다.
