pip 명령어

pip는 파이썬 패키지 관리자(Python Package Installer)로, 파이썬 패키지나 라이브러리를 설치하고 관리하는 데 사용됩니다. 파이썬 패키지 인덱스(PyPI)에서 제공하는 다양한 패키지를 간단하게 설치할 수 있습니다.

주요 pip 명령어

↓
패키지 설치
pip install <패키지명>

주어진 패키지를 설치합니다.

예시
pip install requests
ver
특정 버전 설치
pip install <패키지명>==<버전>

특정 버전의 패키지를 설치할 때 사용합니다.

예시
pip install requests==2.25.1
↑
패키지 업데이트
pip install --upgrade <패키지명>

설치된 패키지를 최신 버전으로 업데이트합니다.

예시
pip install --upgrade numpy
✕
패키지 제거
pip uninstall <패키지명>

설치된 패키지를 제거합니다.

예시
pip uninstall matplotlib
≡
설치된 패키지 목록
pip list

현재 설치된 모든 패키지의 목록과 버전을 확인할 수 있습니다.

i
패키지 정보 확인
pip show <패키지명>

특정 패키지의 설치 경로, 버전, 종속성 등 상세 정보를 확인합니다.

예시
pip show pandas
