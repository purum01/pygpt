인스턴스 사용

인스턴스 생성과 속성 접근
인스턴스(instance)는 클래스(설계도)로부터 실제로 만들어진 객체입니다.

클래스 이름을 함수처럼 호출하면 인스턴스가 생성되고, __init__ 메서드가 자동으로 실행됩니다. 

class Student:
    def __init__(self, name, grade):
        self.name  = name
        self.grade = grade

# 인스턴스 생성
student1 = Student("이준서", 2)
student2 = Student("김민지", 3)

# 속성 접근: 인스턴스.속성명
print(student1.name)    # 이준서
print(student1.grade)   # 2
print(student2.name)    # 김민지
  • student1 = Student("이준서", 2) : 이름이 "이준서"이고 2학년인 학생 인스턴스를 생성합니다.
  • student1.name : 인스턴스의 name 속성값을 읽습니다.
  • 인스턴스는 각자 독립적인 속성 값을 가집니다.
메서드 호출과 속성 변경

메서드 호출

인스턴스에서 메서드를 호출할 때는 인스턴스.메서드명() 형식을 사용합니다. 

class Student:
    def __init__(self, name, grade):
        self.name  = name
        self.grade = grade

    def introduce(self):
        print(f"안녕하세요! 저는 {self.name}이고 {self.grade}학년입니다.")

    def study(self, subject):
        print(f"{self.name}이/가 {subject}을/를 공부합니다.")


student1 = Student("이준서", 2)
student1.introduce()           # 안녕하세요! 저는 이준서이고 2학년입니다.
student1.study("수학")         # 이준서이/가 수학을/를 공부합니다.

속성 값 변경


student1 = Student("이준서", 2)
print(student1.grade)   # 2

student1.grade = 3      # 속성 값 변경
print(student1.grade)   # 3
여러 인스턴스 활용하기
같은 클래스에서 만든 인스턴스들은 서로 독립적이며 각자 다른 속성 값을 가집니다. 

class Student:
    def __init__(self, name, grade, score):
        self.name  = name
        self.grade = grade
        self.score = score

    def introduce(self):
        print(f"{self.name} ({self.grade}학년) - 점수: {self.score}점")


student1 = Student("이준서", 2, 88)
student2 = Student("김민지", 3, 95)
student3 = Student("박서준", 1, 72)

student1.introduce()   # 이준서 (2학년) - 점수: 88점
student2.introduce()   # 김민지 (3학년) - 점수: 95점
student3.introduce()   # 박서준 (1학년) - 점수: 72점

# 리스트에 인스턴스를 담아 for 루프로 활용
students = [student1, student2, student3]
for s in students:
    s.introduce()
카페 메뉴 관리 프로그램 

class MenuItem:
    def __init__(self, name, price, category):
        self.name     = name
        self.price    = price
        self.category = category

    def show(self):
        print(f"[{self.category}] {self.name} - {self.price}원")

    def discount(self, rate):
        discounted = self.price - self.price * rate // 100
        print(f"{self.name} {rate}% 할인 → {discounted}원")


americano  = MenuItem("아메리카노",  4000, "커피")
latte      = MenuItem("카페라떼",    5000, "커피")
green_tea  = MenuItem("녹차 케이크", 6500, "디저트")

# 전체 메뉴 출력
menu_list = [americano, latte, green_tea]
for item in menu_list:
    item.show()

# 할인 적용
americano.discount(10)   # 아메리카노 10% 할인 → 3600원
