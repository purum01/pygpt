함수 호출

기본 함수 호출과 매개변수 전달

기본 함수 호출


def greet():
    return "안녕하세요!"

message = greet()
print(message)   # 안녕하세요!

매개변수와 함께 호출


def add(a, b):
    return a + b

result = add(3, 4)
print(result)    # 7

기본값(default) 매개변수로 호출


def greet(name="친구"):
    return f"안녕하세요, {name}님!"

print(greet())          # 안녕하세요, 친구님!   ← 기본값 사용
print(greet("홍길동"))   # 안녕하세요, 홍길동님! ← 기본값 대체

키워드 인자로 호출

매개변수 이름을 직접 지정하면 순서와 상관없이 호출할 수 있습니다.


def describe_pet(animal, name):
    print(f"저는 {name}이라는 이름의 {animal}을 키우고 있어요.")

# 순서대로 전달
describe_pet("강아지", "초코")

# 키워드 인자로 순서 변경 가능
describe_pet(name="초코", animal="강아지")

가변 매개변수로 호출 (*args)

매개변수 앞에 *를 붙이면 개수에 상관없이 여러 값을 받을 수 있습니다.


def welcome(*names):
    for name in names:
        print(f"{name}님, 환영합니다!")

welcome("철수")
welcome("영희", "민수", "지영")
