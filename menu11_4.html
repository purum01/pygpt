공문 생성하기

질문
다수의 고객사에 동일한 내용의 공문을 작성하려고 합니다. 다음 조건에 따라 파이썬 코드를 생성해주세요. #제목 동일한 내용의 공문 생성하기 #조건 1. 고객사 명단은 customers.txt 에 저장되어 있음 2. 작성할 공문 템플릿은 template.docx 를 사용함 3. template.docx 에서 { } 부분을 다음과 같이 대체 - {company} → "주식회사 푸른하늘" - {number} → "2023-12-Axx" 형식, xx는 01부터 1씩 증가하는 일련번호 - {receiver} → customers.txt 에 저장된 각 고객사 이름 - {sender} → "푸른하늘(주) 데이터분석팀" - {title} → "데이터 처리 및 분석을 위한 관련 자료 요청" 4. 처리된 docx 파일을 고객사 수만큼 "output" 폴더에 생성 5. 파이썬 입문자가 이해할 수 있도록 주석 포함 #출력예시 output/한국전력_공문.docx 파일이 생성되었습니다. output/삼성전자_공문.docx 파일이 생성되었습니다. output/현대자동차_공문.docx 파일이 생성되었습니다.
답변
python-docx는 외부 라이브러리이므로 터미널에서 먼저 설치해야 합니다. 

pip install python-docx
            

import os
from docx import Document

# 파일 경로 설정
customers_file = 'customers.txt'
template_file  = 'template.docx'
output_folder  = 'output'

# 공문에 들어갈 고정 값
company_value = "주식회사 푸른하늘"
sender_value  = "푸른하늘(주) 데이터분석팀"
title_value   = "데이터 처리 및 분석을 위한 관련 자료 요청"

# output 폴더가 없으면 생성
if not os.path.exists(output_folder):
    os.makedirs(output_folder)

# 고객사 명단 읽기
customers = []
with open(customers_file, 'r', encoding='utf-8') as file:
    for line in file:
        customers.append(line.strip())

# 템플릿을 불러와 { } 부분을 대체한 뒤 저장하는 함수
def generate_document(customer, doc_number):
    doc = Document(template_file)

    for paragraph in doc.paragraphs:
        paragraph.text = paragraph.text.replace('{company}',  company_value)
        paragraph.text = paragraph.text.replace('{number}',   doc_number)
        paragraph.text = paragraph.text.replace('{receiver}', customer)
        paragraph.text = paragraph.text.replace('{sender}',   sender_value)
        paragraph.text = paragraph.text.replace('{title}',    title_value)

    output_filename = f"{output_folder}/{customer}_공문.docx"
    doc.save(output_filename)
    print(f"{output_filename} 파일이 생성되었습니다.")

# 고객사별 공문 생성
for i, customer in enumerate(customers, start=1):
    doc_number = f"2023-12-A{str(i).zfill(2)}"
    generate_document(customer, doc_number)
