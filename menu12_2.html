숫자 거꾸로 출력하기

입력받은 숫자를 거꾸로 출력하는 프로그램입니다. 나머지(%)와 몫(//) 연산을 활용합니다.

  • 👉 입력 : 12345
  • 🖥️ 출력 : 54321

print("🔢 숫자 거꾸로 출력하기")
num = int(input("양의 정수를 입력하세요: "))

reversed_num = 0
original     = num

while num > 0:
    digit        = num % 10               # 마지막 자리 숫자 추출
    reversed_num = reversed_num * 10 + digit
    num          = num // 10              # 마지막 자리 제거

print(f"\n입력한 숫자 : {original}")
print(f"거꾸로 출력 : {reversed_num}")
  • ❓질문1 : num % 10 은 어떤 값을 반환하나요? 12345를 예시로 단계별로 설명해보세요.
  • ❓질문2 : 입력한 숫자가 100처럼 0으로 끝나면 출력 결과가 어떻게 달라질까요?
  • 🤔 실습 : 다음 기능을 추가하세요
    1. 입력값이 0 이하이면 "양의 정수를 입력해주세요"를 출력하고 종료하는 기능 구현
    2. 원래 숫자와 거꾸로 된 숫자가 같으면 "회문 숫자입니다!"를 출력하는 기능 구현
구구단 출력기

원하는 단을 입력받아 구구단을 출력하는 프로그램입니다.

  • 👉 입력 : 3
  • 🖥️ 출력 : 3 x 1 = 3  ~  3 x 9 = 27

print("📊 구구단 출력기")
dan = int(input("몇 단을 출력할까요? (2~9): "))

if dan < 2 or dan > 9:
    print("2에서 9 사이의 숫자를 입력해주세요.")
else:
    count = 1
    while count <= 9:
        result = dan * count
        print(f"{dan} x {count} = {result}")
        count = count + 1
  • ❓질문1 : count = count + 1 대신 count += 1 로 쓸 수 있나요?
  • ❓질문2 : 2단부터 9단까지 전체 구구단을 출력하려면 어떻게 바꾸면 될까요?
  • 🤔 실습 : 다음 기능을 추가하세요
    1. 짝수 단(2, 4, 6, 8단)만 출력하는 기능 구현
    2. "그만"을 입력할 때까지 반복해서 구구단을 출력하는 기능 구현
