try - except 문

try - except 구문에 대해 설명해주세요
프로그램을 실행하다 보면 예상치 못한 오류가 발생할 수 있습니다. try-except 구문을 사용하면 오류가 발생해도 프로그램이 갑자기 종료되지 않고, 개발자가 정한 방식으로 처리할 수 있습니다.

기본 구조


try:
    # 오류가 발생할 수 있는 코드
    pass
except 예외타입:
    # 오류가 발생했을 때 실행할 코드
    pass

특정 예외 처리


try:
    number = int(input("숫자를 입력하세요: "))
    print(f"입력한 숫자: {number}")
except ValueError:
    print("숫자가 아닌 값을 입력했습니다.")

모든 예외 처리

예외 타입을 지정하지 않으면 모든 종류의 예외를 한 번에 처리합니다. 단, 어떤 예외인지 알 수 없어 디버깅이 어려울 수 있습니다. 

try:
    result = 10 / 0
except:
    print("알 수 없는 오류가 발생했습니다.")
다중 예외 처리와 예외 인스턴스

다중 예외 처리

여러 개의 except를 사용하면 예외 종류에 따라 다른 처리를 할 수 있습니다. 

def safe_divide(a, b):
    try:
        result = a / b
        print(f"결과: {result}")
    except ZeroDivisionError:
        print("0으로 나눌 수 없습니다.")
    except TypeError:
        print("숫자만 입력해주세요.")

safe_divide(10, 2)    # 결과: 5.0
safe_divide(10, 0)    # 0으로 나눌 수 없습니다.
safe_divide(10, "a")  # 숫자만 입력해주세요.

예외 인스턴스 활용 (as)

as 키워드로 예외 객체를 변수에 담으면 오류 메시지를 출력할 수 있습니다. 

try:
    number = int("abc")
except ValueError as e:
    print(f"오류 내용: {e}")
# 오류 내용: invalid literal for int() with base 10: 'abc'
finally 구문
finally 블록은 예외 발생 여부와 관계없이 항상 실행됩니다. 마무리 작업(안내 메시지 출력 등)에 활용합니다. 

try:
    number = int(input("숫자를 입력하세요: "))
    print(f"입력한 숫자: {number}")
except ValueError:
    print("잘못된 입력입니다.")
finally:
    print("--- 프로그램을 종료합니다 ---")   # 항상 실행
  • 숫자를 올바르게 입력한 경우 → try 실행 → finally 실행
  • 숫자가 아닌 값을 입력한 경우 → except 실행 → finally 실행
주요 예외 예제

ValueError — 잘못된 타입 변환


try:
    number = int("숫자아님")
except ValueError:
    print("ValueError: 숫자가 아닌 값을 int()로 변환하려 했습니다.")

TypeError — 타입 불일치 연산


try:
    result = "안녕" + 5
except TypeError:
    print("TypeError: 문자열과 숫자는 더할 수 없습니다.")

IndexError — 범위를 벗어난 인덱스


books = ["토지", "해리 포터", "삼국지"]
try:
    print(books[5])
except IndexError:
    print("IndexError: 리스트 범위를 벗어난 인덱스입니다.")

KeyError — 존재하지 않는 딕셔너리 키


scores = {"철수": 85, "영희": 92, "민수": 78}
try:
    print(scores["지훈"])
except KeyError:
    print("KeyError: 해당 키가 딕셔너리에 없습니다.")

ZeroDivisionError — 0으로 나누기


try:
    result = 10 / 0
except ZeroDivisionError:
    print("ZeroDivisionError: 0으로 나눌 수 없습니다.")
