가위바위보 게임 (2인용) 

print("✊ 가위바위보 게임 (2인용)")

player1 = input("1번 플레이어 이름: ")
player2 = input("2번 플레이어 이름: ")

choice1 = input(f"{player1}의 선택 (가위/바위/보): ")
choice2 = input(f"{player2}의 선택 (가위/바위/보): ")

print(f"\n{player1}: {choice1}  vs  {player2}: {choice2}")

if choice1 == choice2:
    print("🤝 비겼습니다!")
elif (choice1 == "바위" and choice2 == "가위") or \
     (choice1 == "가위" and choice2 == "보") or \
     (choice1 == "보"   and choice2 == "바위"):
    print(f"🏆 {player1} 승리!")
else:
    print(f"🏆 {player2} 승리!")
  • ❓질문1 : "가위", "바위", "보" 외의 다른 값을 입력했을 때 다시 입력받으려면 어떻게 할까요?
  • ❓질문2 : 3판 2선승제로 만들려면 어떻게 바꾸면 좋을까요?
  • 🤔 실습 : 다음 기능을 추가하세요
