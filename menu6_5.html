dict

dict의 특징과 메소드를 설명해주세요
dict는 키(key)와 값(value) 쌍으로 데이터를 저장하는 자료형입니다. 키로 값을 빠르게 검색할 수 있고, 키는 중복될 수 없습니다.

dict의 주요 특징은 다음과 같습니다.
  • 키(key)는 중복될 수 없으며, 값(value)은 중복될 수 있습니다.
  • 키를 이용해 값을 빠르게 조회·추가·수정·삭제할 수 있습니다.
  • 파이썬 3.7 이후부터 삽입 순서가 유지됩니다.

조회

  • get(key, default) : 키에 해당하는 값을 반환합니다. 키가 없으면 default를 반환합니다. (default 생략 시 None)
  • keys() : 모든 키를 반환합니다.
  • values() : 모든 값을 반환합니다.
  • items() : 모든 키-값 쌍을 (key, value) 형태로 반환합니다.

추가 및 수정

  • dict[key] = value : 키가 있으면 값을 수정하고, 없으면 새 항목을 추가합니다.
  • update(other) : 다른 딕셔너리의 내용을 현재 딕셔너리에 추가·수정합니다.

제거

  • pop(key) : 키에 해당하는 항목을 제거하고 값을 반환합니다. 키가 없으면 KeyError가 발생합니다.
dict 메소드 예제 코드를 보여주세요 

person = {'name': 'Alice', 'age': 25}

# 추가 / 수정
person['city'] = 'Seoul'          # 새 키 추가
person['age']  = 26               # 기존 값 수정
print(person)

# 조회
print(person.get('name'))         # 'Alice'
print(person.get('job', '없음'))  # 키가 없으면 '없음' 반환

# keys / values / items
print(list(person.keys()))        # ['name', 'age', 'city']
print(list(person.values()))      # ['Alice', 26, 'Seoul']
print(list(person.items()))       # [('name','Alice'), ('age',26), ('city','Seoul')]

# for 루프와 items() 조합
for key, value in person.items():
    print(f"{key} : {value}")

# update
person.update({'job': '개발자', 'age': 27})
print(person)

# pop
removed = person.pop('city')
print(f"제거된 값: {removed}")
print(person)
좋아하는 색깔 조사하기 

favorite_colors = {
    '영희': '파란색',
    '철수': '녹색',
    '민수': '빨간색'
}

# 새 친구 추가
favorite_colors['지민'] = '노란색'
print(f"지민 추가 후: {favorite_colors}")

# 철수의 색깔 변경
favorite_colors['철수'] = '보라색'
print(f"철수 변경 후: {favorite_colors}")

# 영희의 색깔 확인
print(f"영희의 색깔: {favorite_colors.get('영희')}")

# 없는 사람 조회 (기본값 반환)
print(f"수진의 색깔: {favorite_colors.get('수진', '미응답')}")
과일 가격표 만들기 

fruit_prices = {
    '사과': 1000,
    '바나나': 500,
    '오렌지': 1500
}

# 전체 가격표 출력
for fruit, price in fruit_prices.items():
    print(f"{fruit} : {price}원")

# 신규 과일 추가
fruit_prices.update({'딸기': 2000, '포도': 3000})

# 특정 과일 가격 확인
print(f"\n딸기 가격: {fruit_prices.get('딸기', '정보 없음')}원")

# 단종된 과일 제거
fruit_prices.pop('바나나')
print(f"바나나 제거 후: {list(fruit_prices.keys())}")
