클래스 선언

클래스(class)란 무엇인가요?
클래스(class)는 관련된 데이터(속성)와 동작(메서드)을 하나로 묶은 설계도입니다.

붕어빵 틀에 비유할 수 있습니다. 붕어빵 틀(클래스)로 여러 개의 붕어빵(인스턴스)을 찍어낼 수 있는 것처럼, 클래스를 정의해두면 같은 구조의 객체를 여러 개 만들 수 있습니다.

예를 들어, "학생"이라는 클래스가 있다면
  • 속성(데이터) : 이름, 학년, 점수 등
  • 메서드(동작) : 자기소개하기, 공부하기 등
클래스 선언과 생성자(__init__)
클래스는 class 키워드로 선언하고, __init__ 메서드로 속성의 초기값을 설정합니다.

기본 구조


class Student:
    def __init__(self, name, grade):
        self.name  = name   # 이름 속성
        self.grade = grade  # 학년 속성
  • class Student: Student라는 이름의 클래스를 선언합니다.
  • __init__: 인스턴스가 생성될 때 자동으로 호출되는 생성자입니다.
  • self: 생성된 인스턴스 자기 자신을 가리킵니다. 항상 첫 번째 매개변수로 작성합니다.
  • self.name = name: 인스턴스에 name 속성을 저장합니다.

클래스로 인스턴스 만들기


student1 = Student("이준서", 2)   # Student 클래스의 인스턴스 생성
student2 = Student("김민지", 3)

print(student1.name)   # 이준서
print(student2.grade)  # 3
메서드(method) 추가하기
클래스 안에 함수를 정의하면 그것이 메서드입니다. 메서드도 항상 첫 번째 매개변수로 self를 받습니다. 

class Student:
    def __init__(self, name, grade):
        self.name  = name
        self.grade = grade

    def introduce(self):
        print(f"안녕하세요! 저는 {self.name}이고 {self.grade}학년입니다.")

    def study(self, subject):
        print(f"{self.name}이/가 {subject}을/를 공부합니다.")


student1 = Student("이준서", 2)
student1.introduce()          # 안녕하세요! 저는 이준서이고 2학년입니다.
student1.study("파이썬")      # 이준서이/가 파이썬을/를 공부합니다.
  • 메서드는 클래스 안에 들여쓰기로 정의합니다.
  • 메서드 내부에서 속성에 접근할 때는 self.속성명으로 씁니다.
  • 메서드 호출은 인스턴스.메서드명() 형식으로 합니다.
