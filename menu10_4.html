Pandas 기초

Pandas란? 설치 방법
Pandas는 파이썬에서 표(행·열) 형태의 데이터를 다루는 라이브러리입니다. 엑셀처럼 데이터를 읽고 필터링하고 분석할 수 있습니다.

설치 방법

Pandas는 표준 모듈이 아니므로 터미널에서 먼저 설치해야 합니다. 

pip install pandas

DataFrame이란?

Pandas의 핵심 자료구조입니다. 행(row)과 열(column)로 이루어진 2차원 표입니다. 

import pandas as pd

data = {
    '이름': ['이준서', '김민지', '박서준', '최지우'],
    '나이': [25, 30, 35, 28],
    '도시': ['서울', '부산', '대구', '인천'],
    '점수': [88.5, 92.3, 85.6, 90.1]
}

df = pd.DataFrame(data)
print(df)
# 결과:
#     이름  나이  도시    점수
# 0  이준서  25  서울  88.5
# 1  김민지  30  부산  92.3
# 2  박서준  35  대구  85.6
# 3  최지우  28  인천  90.1
CSV 파일 저장과 읽기
실제 업무에서는 DataFrame을 CSV 파일로 저장하거나, CSV 파일을 불러와 DataFrame으로 만드는 작업이 가장 많습니다.

예제 코드


import pandas as pd

data = {
    '이름': ['이준서', '김민지', '박서준', '최지우'],
    '나이': [25, 30, 35, 28],
    '도시': ['서울', '부산', '대구', '인천'],
    '점수': [88.5, 92.3, 85.6, 90.1]
}
df = pd.DataFrame(data)

# DataFrame을 CSV 파일로 저장 (index=False: 행 번호 제외)
df.to_csv('students.csv', index=False, encoding='utf-8-sig')
print("저장 완료!")

# CSV 파일 불러오기
df2 = pd.read_csv('students.csv')
print(df2)
  • to_csv() : DataFrame을 CSV 파일로 저장합니다.
  • read_csv() : CSV 파일을 DataFrame으로 불러옵니다.
  • encoding='utf-8-sig' : 한글이 포함된 경우 인코딩을 지정해 엑셀에서 깨지지 않도록 합니다.
데이터 확인하기
데이터를 불러온 후 가장 먼저 하는 작업입니다. 데이터의 크기, 구조, 각 열의 타입을 파악합니다.

예제 코드


import pandas as pd

df = pd.read_csv('students.csv')

print(df.shape)       # 행 수, 열 수 → (4, 4)
print(df.head())      # 앞 5행 출력
print(df.tail(2))     # 뒤 2행 출력
print(df.info())      # 열 이름, 데이터 타입, 결측값 여부
print(df.describe())  # 수치형 열의 통계 요약 (평균, 최대, 최소 등)
  • shape : (행 수, 열 수) 튜플을 반환합니다.
  • head(n) : 앞 n행을 출력합니다. 기본값은 5입니다.
  • info() : 열 이름, 데이터 타입, 결측값 개수를 보여줍니다.
  • describe() : 수치형 열의 평균·표준편차·최소·최대 등을 요약합니다.
열 선택과 행 접근
DataFrame에서 원하는 열이나 행을 선택하는 방법입니다.

예제 코드


import pandas as pd

df = pd.read_csv('students.csv')

# 특정 열 하나 선택 → Series 반환
print(df['이름'])

# 여러 열 선택 → DataFrame 반환
print(df[['이름', '점수']])

# loc: 인덱스 번호로 특정 행 선택
print(df.loc[0])      # 첫 번째 행
print(df.loc[1, '이름'])  # 1번 행의 '이름' 열 값
  • df['열이름'] : 열 하나를 선택합니다.
  • df[['열1', '열2']] : 여러 열을 선택합니다.
  • df.loc[행번호] : 행 번호로 특정 행을 선택합니다.
  • df.loc[행번호, '열이름'] : 특정 행의 특정 열 값을 선택합니다.
데이터 필터링
조건에 맞는 행만 골라내는 작업입니다. 엑셀의 '필터' 기능과 같습니다.

예제 코드


import pandas as pd

df = pd.read_csv('students.csv')

# 나이가 30 이상인 행만 선택
print(df[df['나이'] >= 30])

# 점수가 90 이상인 행만 선택
print(df[df['점수'] >= 90])

# 여러 조건 동시 적용 (&: 그리고, |: 또는)
print(df[(df['나이'] >= 28) & (df['점수'] >= 90)])

# 특정 도시의 데이터만 선택
print(df[df['도시'] == '서울'])
  • 조건을 여러 개 쓸 때는 각 조건을 괄호로 묶고 &(그리고) 또는 |(또는)로 연결합니다.
데이터 정렬
sort_values()로 특정 열을 기준으로 오름차순·내림차순 정렬할 수 있습니다.

예제 코드


import pandas as pd

df = pd.read_csv('students.csv')

# 나이 기준 오름차순 정렬
print(df.sort_values(by='나이'))

# 점수 기준 내림차순 정렬
print(df.sort_values(by='점수', ascending=False))

# 여러 열 기준 정렬 (나이 오름차순 → 점수 내림차순)
print(df.sort_values(by=['나이', '점수'], ascending=[True, False]))
열 추가와 행 추가
DataFrame에 새로운 열이나 행을 추가하는 방법입니다.

예제 코드


import pandas as pd

df = pd.read_csv('students.csv')

# 새로운 열 추가 (점수에 10점 보너스)
df['보너스점수'] = df['점수'] + 10
print(df)

# 새로운 행 추가
new_row = pd.DataFrame([{'이름': '정하은', '나이': 27, '도시': '광주', '점수': 94.0, '보너스점수': 104.0}])
df = pd.concat([df, new_row], ignore_index=True)
print(df)
  • df['새열이름'] = 값 : 새로운 열을 추가합니다.
  • pd.concat() : 두 DataFrame을 세로로 합칩니다. ignore_index=True로 인덱스를 새로 매깁니다.
통계 요약과 그룹 집계
데이터의 평균·합계 등 통계값을 구하거나, 특정 열을 기준으로 그룹별 집계를 할 수 있습니다.

기본 통계


import pandas as pd

df = pd.read_csv('students.csv')

print(df['점수'].mean())   # 평균
print(df['점수'].max())    # 최댓값
print(df['점수'].min())    # 최솟값
print(df['점수'].sum())    # 합계
print(df.describe())       # 전체 통계 요약

describe() 결과 항목 설명

  • count : 결측값을 제외한 데이터 개수
  • mean : 평균값
  • std : 표준편차 (데이터가 평균에서 얼마나 퍼져 있는지)
  • min / max : 최솟값 / 최댓값
  • 25% / 50% / 75% : 사분위수 (데이터를 4등분했을 때의 경계값)
결측값(NaN) 처리
실제 데이터에는 값이 없는 결측값(NaN)이 자주 있습니다. 결측값을 그냥 두면 계산 오류가 발생하므로 반드시 처리해야 합니다.

예제 코드


import pandas as pd
import numpy as np

data = {
    '이름': ['이준서', '김민지', '박서준', '최지우'],
    '나이': [25, None, 35, 28],
    '점수': [88.5, 92.3, None, 90.1]
}
df = pd.DataFrame(data)

# 결측값 확인
print(df.isnull())         # True/False 표로 표시
print(df.isnull().sum())   # 열별 결측값 개수

# 결측값 제거 (결측값이 있는 행 전체 삭제)
df_drop = df.dropna()
print(df_drop)

# 결측값 채우기 (나이는 0, 점수는 평균으로)
df['나이']  = df['나이'].fillna(0)
df['점수'] = df['점수'].fillna(df['점수'].mean())
print(df)
  • isnull() : 결측값 위치를 True/False로 반환합니다.
  • dropna() : 결측값이 있는 행을 제거합니다.
  • fillna(값) : 결측값을 지정한 값으로 채웁니다.
