set

set의 특징과 메소드를 설명해주세요
set은 순서가 없고 중복을 허용하지 않는 자료형입니다. 리스트에서 중복 값을 제거하거나, 두 데이터 집합 사이의 공통 요소·차이를 분석할 때 유용합니다.

set의 주요 특징은 다음과 같습니다.
  • 순서가 없어 인덱스로 접근할 수 없습니다.
  • 같은 값은 하나만 저장됩니다. (중복 자동 제거)
  • 요소를 추가·제거할 수 있습니다. (mutable)

요소 추가 및 제거

  • add(x) : 집합에 요소 x를 추가합니다.
  • remove(x) : 집합에서 요소 x를 제거합니다. x가 없으면 KeyError가 발생합니다.
  • discard(x) : 집합에서 요소 x를 제거합니다. x가 없어도 오류가 발생하지 않습니다.

집합 연산

  • union(other) : 합집합을 반환합니다. ( | 연산자로도 사용 가능 )
  • intersection(other) : 교집합을 반환합니다. ( & 연산자로도 사용 가능 )
  • difference(other) : 차집합을 반환합니다. ( - 연산자로도 사용 가능 )
set 메소드 예제 코드를 보여주세요 

# set 생성 — 중복은 자동으로 제거됨
my_set = {1, 2, 3, 2, 1}
print(my_set)   # {1, 2, 3}

# add / remove / discard
my_set.add(4)
print(my_set)          # {1, 2, 3, 4}

my_set.remove(2)
print(my_set)          # {1, 3, 4}

my_set.discard(99)     # 없는 값도 오류 없이 실행됨
print(my_set)          # {1, 3, 4}

# 집합 연산
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a.union(b))           # {1, 2, 3, 4, 5, 6}  합집합
print(a.intersection(b))    # {3, 4}               교집합
print(a.difference(b))      # {1, 2}               차집합 (a에만 있는 것)

# 연산자 표현
print(a | b)   # 합집합
print(a & b)   # 교집합
print(a - b)   # 차집합
학급 애완동물 종류 세기 

# 설문에서 수집한 애완동물 목록 (중복 있음)
pets_list = ['강아지', '고양이', '햄스터', '강아지', '토끼', '고양이', '강아지']

# set으로 변환하면 중복이 자동 제거됨
pets_set = set(pets_list)

print(f"전체 응답 수 : {len(pets_list)}개")   # 7개
print(f"애완동물 종류 : {pets_set}")
print(f"종류 수 : {len(pets_set)}가지")        # 4가지
동아리 회원 명단 정리하기 

science_club = {'지우', '철수', '영희'}
math_club    = {'민수', '영희', '지우'}

# 두 동아리 모두 가입한 학생 (교집합)
both = science_club.intersection(math_club)
print(f"두 동아리 모두 가입: {both}")

# 과학 동아리에만 가입한 학생 (차집합)
science_only = science_club.difference(math_club)
print(f"과학 동아리만 가입: {science_only}")

# 전체 동아리 회원 (합집합)
all_members = science_club.union(math_club)
print(f"전체 회원: {all_members}")
