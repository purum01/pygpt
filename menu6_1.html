str

자주 사용하는 str 메소드를 설명해주세요
파이썬의 str 객체는 문자열을 다루기 위한 다양한 메소드를 제공합니다. 아래는 실무에서 자주 사용하는 메소드들입니다.

변환

  • upper() : 문자열의 모든 문자를 대문자로 변환합니다.
  • lower() : 문자열의 모든 문자를 소문자로 변환합니다.
  • title() : 각 단어의 첫 글자를 대문자로 변환합니다.

검색과 교체

  • count(sub) : 부분 문자열 sub이 문자열 내에서 등장하는 횟수를 반환합니다.
  • startswith(prefix) : 문자열이 특정 접두사로 시작하는지 확인합니다.
  • endswith(suffix) : 문자열이 특정 접미사로 끝나는지 확인합니다.
  • find(sub) : sub이 처음 발견되는 위치를 반환합니다. 없으면 -1을 반환합니다.
  • replace(old, new) : old 문자열을 new 문자열로 교체합니다.

분할과 결합

  • split(sep) : 문자열을 sep 기준으로 분할하여 리스트로 반환합니다.
  • join(iterable) : iterable의 항목 사이에 문자열을 삽입하여 하나로 결합합니다.

공백 처리

  • strip() : 문자열 양쪽 끝의 공백을 제거합니다.
  • lstrip() : 문자열 왼쪽 끝의 공백을 제거합니다.
  • rstrip() : 문자열 오른쪽 끝의 공백을 제거합니다.

검증

  • isdigit() : 모든 문자가 숫자인지 확인합니다.
  • isalpha() : 모든 문자가 알파벳인지 확인합니다.
  • isalnum() : 모든 문자가 알파벳 또는 숫자인지 확인합니다.
  • islower() : 모든 알파벳 문자가 소문자인지 확인합니다.
  • isupper() : 모든 알파벳 문자가 대문자인지 확인합니다.
str 메소드 예제 코드를 보여주세요 
                
# 변환
text = "hello world"
print(text.upper())   # 'HELLO WORLD'
print(text.lower())   # 'hello world'
print(text.title())   # 'Hello World'

# 검색과 교체
message = "Hello, welcome to the jungle"
print(message.count('e'))               # 3
print(message.startswith('Hello'))      # True
print(message.endswith('jungle'))       # True
print(message.find('welcome'))          # 7
print(message.replace('jungle', 'world'))  # 'Hello, welcome to the world'

# 분할과 결합
data = "apple,banana,cherry"
print(data.split(','))                  # ['apple', 'banana', 'cherry']
print(' '.join(['Join', 'us', 'now']))  # 'Join us now'

# 공백 처리
sample = "   Python   "
print(sample.strip())   # 'Python'
print(sample.lstrip())  # 'Python   '
print(sample.rstrip())  # '   Python'

# 검증
print("12345".isdigit())   # True
print("Python".isalpha())  # True
print("Python3".isalnum()) # True
print("python".islower())  # True
print("PYTHON".isupper())  # True
이름 태그 만들기 
                
# strip() · upper() · split() · join() 활용
raw = input("이름을 입력하세요 (예: hong gil dong): ")
name = raw.strip()                  # 앞뒤 공백 제거
words = name.split()                # 단어 분리
tag = "-".join(words).upper()       # 단어를 -로 연결 후 대문자 변환
print(f"태그: [{tag}]")             # [HONG-GIL-DONG]
