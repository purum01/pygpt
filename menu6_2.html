자주 사용하는 list 메소드를 설명해주세요
파이썬의 list 객체는 요소를 추가, 삭제, 검색, 정렬하는 다양한 메소드를 제공합니다.

추가

  • append(x) : 리스트의 끝에 요소 x를 추가합니다.
  • extend(iterable) : 다른 리스트(또는 iterable)의 모든 요소를 끝에 추가합니다.
  • insert(i, x) : 지정된 위치 i에 요소 x를 삽입합니다.

제거

  • remove(x) : 값이 x와 같은 첫 번째 항목을 삭제합니다. 없으면 오류가 발생합니다.
  • pop() : 리스트의 마지막 요소를 제거하고 반환합니다. 인덱스를 지정하면 해당 위치의 요소를 제거합니다.

검색

  • index(x) : 값이 x인 첫 번째 항목의 위치를 반환합니다. 없으면 오류가 발생합니다.
  • count(x) : 값이 x인 항목의 개수를 반환합니다.

정렬

  • sort() : 리스트의 요소를 오름차순으로 정렬합니다. reverse=True 를 지정하면 내림차순으로 정렬합니다.
  • reverse() : 리스트의 요소 순서를 뒤집습니다.
list 메소드 예제 코드를 보여주세요 

fruits = ['바나나', '오렌지', '사과', '포도']

# 추가
fruits.append('딸기')          # ['바나나', '오렌지', '사과', '포도', '딸기']
fruits.insert(1, '키위')       # ['바나나', '키위', '오렌지', '사과', '포도', '딸기']
fruits.extend(['망고', '수박']) # 끝에 여러 요소 추가

# 제거
fruits.remove('오렌지')        # '오렌지' 삭제
last = fruits.pop()            # 마지막 요소 제거 후 반환

# 검색
idx = fruits.index('사과')     # '사과'의 위치 반환
print(idx)

numbers = [1, 2, 3, 2, 1, 2]
print(numbers.count(2))        # 3

# 정렬
scores = [85, 92, 78, 95, 88]
scores.sort()                  # 오름차순: [78, 85, 88, 92, 95]
scores.sort(reverse=True)      # 내림차순: [95, 92, 88, 85, 78]

items = ['banana', 'apple', 'cherry']
items.reverse()                # ['cherry', 'apple', 'banana']
