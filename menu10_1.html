라이브러리 사용하기

파이썬에서 라이브러리를 사용하려면 import 문으로 해당 라이브러리를 먼저 가져와야 합니다. 특정 기능만 필요한 경우 그 부분만 선택적으로 가져올 수도 있습니다.

import 전체 라이브러리 가져오기

라이브러리 전체를 가져옵니다. 이후 라이브러리명.함수명 형식으로 기능을 사용합니다. 

import math
print(math.sqrt(16))  # 16의 제곱근을 출력
as 별칭(alias) 사용하기

라이브러리를 짧은 별칭으로 가져옵니다. 코드를 간결하게 작성할 수 있어 numpy, pandas 같이 자주 쓰는 라이브러리에서 많이 사용합니다. 

import math as m
print(m.sqrt(16))  # 16의 제곱근을 출력
💡 관례적으로 import numpy as np, import pandas as pd처럼 약어를 사용합니다.
from 특정 함수만 가져오기

라이브러리에서 필요한 함수나 클래스만 선택적으로 가져옵니다. 가져온 후에는 라이브러리명 없이 바로 함수를 사용할 수 있습니다. 

from math import sqrt
print(sqrt(16))  # 16의 제곱근을 출력
